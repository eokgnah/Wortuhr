Wortuhr ESP32-S3 Web Installer

Erstinstallation für ESP32-S3 Super Mini mit 4 MB Flash + 2 MB PSRAM.

Firmware

Wortuhr_ESP32_20260823

Empfohlenes Build: 4MB Flash · Minimal SPIFFS · OTA-fähig · QSPI PSRAM

Bitte Chrome/Edge oder einen anderen Browser mit Web Serial verwenden.

Wichtig

Für die Erstinstallation wird die .merged.bin verwendet. Sie enthält Bootloader, Partitionstabelle und Anwendung in einem einzigen Image.

Wenn bereits eine andere Firmware/Partitionierung auf dem Board ist, im Installer möglichst Erase device wählen.

Benötigte Datei

Lege die exportierte Datei

Wortuhr_ESP32_20260823.ino.merged.bin

in den Ordner firmware/ dieses Pakets bzw. an dieselbe Stelle im GitHub-Repository.
